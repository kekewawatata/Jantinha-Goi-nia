## Jantinha Goiânia

Sistema de gestão desenvolvido para controlar as operações de um negócio de venda de refeições caseiras, centralizando processos que normalmente são geridos de forma fragmentada em planilhas.

## Funcionalidades

- **Controle de Gastos** — registro, categorização e acompanhamento das despesas operacionais
- **Controle de Atendimento** — gestão de pedidos, clientes e histórico de vendas
- **Controle de Estoque** — monitoramento de insumos e produtos disponíveis, com rastreamento de entradas e saídas

## Stack Técnica

- **Framework:** Next.js
- **Estilização:** Tailwind CSS
- **Infraestrutura:** Deploy na Hostinger

## Instalação e Execução

```bash
npm install
npm run dev
```

A aplicação ficará disponível em `http://localhost:3000`.

## Configuração

Copie o arquivo `.env.example` para `.env` e preencha as variáveis necessárias antes de executar o projeto.
